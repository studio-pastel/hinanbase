# 自治体への照会の進め方（案）

`docs/DATA_NOTES.md` 17 章の続き。照会先は `data/inquiry/targets.csv`（167 市町村、`npm run data:inquiry-targets` で作り直せる）。

照会の送信は運営者が行う（外部への連絡で、請求者の名前が要るため）。このリポジトリでは文案・記録・回答の取り込みを用意する。

## 1. 方針

- **相手の負担を小さくする**：新しく調べてもらうのではなく、**すでにある資料の写し**をお願いする。避難所カルテ、施設台帳、備蓄・設備の一覧などで、様式は問わない。
- **ないことも大事な回答**：資料が存在しない場合は「ない」と答えてもらえれば十分。その回答も記録する。
- **段階を踏む**：まず問い合わせ（費用なし、回答の義務なし）。1 か月たって回答がなければ、一度だけ催促する。それでもなければ、情報公開請求を検討する。請求するかどうかは、市町村ごとに運営者が判断する。
- **公開の仕方**：回答は、出典（市町村名・回答日・資料名）を付けて施設ごとの設備の値として載せる。照会の記録（いつ・何を依頼し・どう回答があったか）も公開する。自治体を比べる順位や点数は作らない。
- **個人の情報は扱わない**：依頼は施設の設備だけ。避難者や職員の個人情報は求めない。

## 2. 依頼する項目（優先順）

命にかかわる設備（DATA_NOTES 16.3）のうち、公開資料で埋まらなかったもの。

| 優先 | 項目 | 尋ねること | 設備項目 |
|---|---|---|---|
| 1 | 主要な滞在スペース（体育館など）の暖房 | 有無、方式・熱源（灯油・ガス・電気など）、停電時に使えるか | `heating_main_hall` |
| 2 | 非常用電源 | 発電機・蓄電池の有無、何を動かせるか（照明だけ／暖房も） | `power_backup`・`solar_battery` |
| 3 | 断水時のトイレ | マンホールトイレ、携帯・簡易トイレの備蓄、井戸・プール水の利用 | `toilet_water_outage` |
| 4 | 簡易ベッド | 段ボールベッドなどの備蓄の有無・数 | `bed_kit` |
| 5 | 給水 | 受水槽・耐震性貯水槽・井戸の有無 | `water_supply` |

1 つでも分かれば十分であることを、文面に書く。

## 3. 文案（メール・問い合わせフォーム用）

```
件名：指定避難所の設備（暖房・非常用電源など）の資料についてのお問い合わせ

○○市（町・村）防災担当 御中

突然のご連絡失礼いたします。
「HinanBase」（https://hinanbase.pages.dev/）という、全国の指定避難所の設備の
公開状況を整理する非営利のウェブサイトを運営している［氏名］と申します。

令和6年能登半島地震では、避難所の寒さやトイレの問題が災害関連死の一因として
報告されています（内閣府「災害関連死事例集」令和8年1月）。
冬季の災害に備え、指定避難所ごとの設備が分かる資料を探しております。

つきましては、貴市（町・村）の指定避難所について、次の設備が分かる既存の資料
（避難所カルテ、施設台帳、備蓄一覧など。様式は問いません）があれば、
写しまたは掲載先をお教えいただけないでしょうか。

　1. 体育館など主に滞在する場所の暖房（有無、方式・熱源、停電時に使えるか）
　2. 非常用電源（発電機・蓄電池の有無）
　3. 断水時のトイレ（マンホールトイレ、携帯トイレの備蓄など）
　4. 簡易ベッド（段ボールベッドなど）の備蓄
　5. 給水設備（受水槽・井戸など）

一部の項目だけでも大変ありがたく存じます。
また、該当する資料がない場合は、その旨だけご返信いただければ幸いです。

いただいた情報は、出典（貴市町村名・回答日・資料名）を明記したうえで、
施設ごとの設備の情報として同サイトに掲載させていただく予定です。
掲載を望まれない内容があればお知らせください。個人情報は一切求めておりません。

ご多忙のところ恐れ入りますが、ご検討のほどよろしくお願いいたします。

［氏名］
［連絡先メールアドレス］
```

- ［氏名］［連絡先］は運営者が記入する。リポジトリ（公開）には書かない。
- 催促（1 か月後に 1 回だけ）は、「先日お問い合わせした件について、ご状況をお伺いできれば幸いです」程度の短い文にする。

## 4. 照会の記録（承認後に実装。DATA_NOTES 17.4 の 3）

市町村ごとに残す項目。

| 項目 | 例 |
|---|---|
| 市町村 | 秋田県仙北市（05215） |
| 送った日・方法 | 2026-12-01、問い合わせフォーム |
| 依頼の内容 | 文案の版（例：v1） |
| 状況 | 送付済み／回答あり／資料なしの回答／回答なし／情報公開請求中 |
| 回答日・要旨 | 2026-12-10、体育館は全校 FF 式灯油暖房、停電時は不可 |
| 受け取った資料 | ファイル（個人情報がないことを確認してから保管） |
| 取り込んだ値 | 施設ごとの設備の値に、この回答を出典として付ける |

記録の置き場は、リポジトリ内の JSON（`data/inquiry/log.json`）を想定する。Supabase は使わない。画面には、市町村の一覧ページに「照会の記録」として出す（順位・点数は付けない）。
